# Logo skill prompts

Select the Logo Generator plugin in ChatGPT, then copy a prompt into the chat. Replace bracketed fields and remove optional lines you do not need.

## Fill-in template

```text
Use Logo Generator to create a logo.
Brand name: [exact spelling]
Business: [what the brand does]
Audience: [who it serves]
Style: [minimal / elegant / playful / vintage / other]
Color theme: [names or hex values]
Logo type: [wordmark / monogram / symbol / combination / emblem / mascot]
Symbol preferences: [include or avoid]
Typography: [optional preference]
Tagline: [exact text, or no tagline]
Use: [website / social profile / packaging / sign]
Layout: [horizontal / stacked / square]
Background: [transparent / solid color]
Output: [PNG / editable SVG]
Number of concepts: [number]
```


## Expanded image-generation prompt example

For the café example, the skill can produce this concrete tool prompt:

```text
Use case: logo-brand
Primary request: Create a welcoming logo for a neighborhood café.
Exact brand text: "Leaf & Bean"
Logo type: Combination mark.
Style: Minimal, warm, and approachable; clean flat shapes.
Symbol: A simple coffee-bean shape with a subtle leaf detail.
Typography: Readable lettering with balanced spacing.
Color palette: Forest green on cream.
Composition: One centered logo with comfortable clear space and a symbol balanced with the wordmark.
Background: Solid cream.
Constraints: Render "Leaf & Bean" exactly, including the ampersand. No tagline, extra lettering, mockup scene, watermark, texture, or unnecessary fine detail.
```
